#  OpenClaw-test  
## 本地强化型 AI Agent 执行框架（Local-First Agent Framework）

**版本**：v2.5.3  
**部署形态**：本地化 / 私有化部署  
**当前模型**：Qwen2.5-7B / 云端gpt-oss:120b（Ollama）

---

## 一、项目简介

**OpenClaw** 是一个面向本地环境的强化型 AI Agent 框架，基于本地大语言模型（LLM）构建，提供**对话理解、任务规划、工具执行与外部系统联动**的一体化能力。

与传统“仅对话式”AI 不同，OpenClaw 以 **Agent 执行能力** 为核心设计目标，支持：

- 本地文件系统感知与操作  
- 自动化执行受控指令  
- 外部 API（如 GitHub）联动  
- 流式交互与可观测执行过程  
- 可扩展的长期记忆与知识增强能力

适用于以下场景：

- 企业内部研发辅助  
- 私有化 AI 助手  
- 自动化工具编排  
- Agent 能力验证与研究  

---

## 二、整体架构与目录结构

OpenClaw 采用 **分层解耦架构**，各层职责清晰，便于能力扩展与企业级演进。

```text
OpenClaw/
├── Gateway/            # 核心网关层：API / WebSocket 接入 + Planner（任务规划）
├── Bridge/             # 调度桥接层：Agent 思考-执行循环控制（Dispatcher）
├── LLM/                # 模型适配层：对接 Ollama OpenAI 兼容接口
├── Tools/              # 工具层：文件系统、GitHub API、系统能力
├── UI/                 # 前端界面：HTML / JS 流式对话交互
├── Memory/             # 记忆层（Phase 4）：向量数据库 + SQLite
├── Config/             # 配置管理：.env、Token 与运行参数
└── main.py             # 系统入口：FastAPI 服务启动
```
## 三、已实现功能阶段（Phase 1–4）

OpenClaw 当前已完成前三个阶段的核心能力建设，覆盖模型接入、通信机制以及基础 Agent 执行能力。

---

### Phase 1 & Phase 2：通信与模型交互能力

#### 1. 本地大模型接入能力

- 采用 **Ollama** 作为本地模型运行时
- 通过 **OpenAI 兼容接口协议**进行模型适配
- 当前默认模型：
  - `Qwen2.5-7B`

该设计确保模型层可被快速替换或扩展至其他本地 / 私有模型。

---

#### 2. 流式交互与通信机制

- 基于 **WebSocket** 实现双向实时通信
- 支持 **Token 级别流式输出**
- 前端具备打字机效果，提升交互可读性与体验

---

#### 3. 服务生命周期管理

- 基于 **FastAPI** 构建高性能服务
- 支持：
  - 服务优雅启动
  - 异常中断处理
  - 资源释放与关闭钩子

---

### Phase 3：Agent 执行能力与工具调用（当前阶段）

Phase 3 是 OpenClaw 从“对话系统”迈向“执行型 Agent”的关键阶段。

---

#### 3.1 本地文件系统工具能力

通过 Tool 层封装，实现对本地文件系统的受控访问：

- `list_files`
  - 查看当前项目目录结构

- `read_file`
  - 读取指定文件内容（源码 / 配置）

- `write_file`
  - 新建或重写文件（受限路径）

所有文件操作均不直接暴露系统权限，确保安全可控。

---

#### 3.2 GitHub API 联动能力

- 支持运行时动态注入 GitHub Token：
  - `github_set_token`

- 支持远程 GitHub 操作：
  - 根据用户意图创建新的 Repository
  - 为后续代码生成、项目初始化提供基础能力

---

#### 3.3 Agent 自我修正机制（基础版）

- 当工具调用失败（如参数错误、API 异常）时：
  - LLM 能基于错误信息进行分析
  - 自动尝试第二轮修正调用

该机制初步具备 **“失败 → 反馈 → 再执行”** 的 Agent 行为闭环。
---
## 四、Phase 4 规划：知识库增强与复杂任务编排

Phase 4 的目标是将 OpenClaw 从“工具执行型 Agent”升级为：

> **具备长期记忆、上下文理解与任务编排能力的本地专家型 Agent**

## 五、快速开始（本地部署）

### 5.1 环境准备

1. 安装并启动 Ollama
2. 拉取所需模型：

```bash
ollama pull qwen2.5:7b
```
启动服务：
```bash
python main_v2_5_3.py
```
